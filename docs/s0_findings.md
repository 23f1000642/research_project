# S0 sanity run: findings (seq-CIFAR-10, class-IL, buffer 500, seeds 0-1)

Source: Kaggle 2xT4, commit `297a27f`, raw numbers in `tables/s0_summary.md` (generated by
`analysis/summarize.py`), per-run files in `results/seq-cifar10-*`. Two seeds only: everything below
is a sanity check, not a paper result.

## Accuracy vs. Buzzega et al. 2020 (Table 2)

| method | ours (s0 / s1) | published | verdict |
|---|---|---|---|
| SGD | 19.80 / 18.67 | 19.62 ± 0.05 | matches |
| ER | 65.65 / 55.39 | 57.74 ± 0.27 | mean 60.5, within noise of 2 seeds |
| DER++ | 75.13 / 58.96 | 72.70 ± 1.36 | seed 1 is an outlier |

An earlier interactive run of the same code (commit `6aa2487`, files lost) gave SGD 19.72 / 19.25,
ER 64.74 / 60.71, DER++ 75.02 / 69.00. Same seed and configuration, so the run-to-run spread is
large: DER++ seed 1 gave 69.00 there and 58.96 here.

Where the 58.96 comes from: after task 3 that run was at 74.8 %, and after the last task even the
*current* task is only 74.4 % (seed 0: 91.9 %) while the training loss is low. The model is
evaluated at the last step of 50 epochs at a constant learning rate of 0.03, so the end-of-task
snapshot is noisy. Candidate fix to test (not yet verified): decay the learning rate near the end of
each task, as later Mammoth versions do, and check that the per-seed spread shrinks.

## First look at H1 ("confident forgetting"), preliminary

After the last task, MSP confidence vs. accuracy on old tasks (mean of 2 seeds, %):

| method | old-task acc | old-task confidence | gap | CER@0.9 old | AUROC old |
|---|---|---|---|---|---|
| SGD | 0.0 | 96.6 | 96.6 | 89.2 | - |
| ER | 51.5 | 93.8 | 42.3 | 72.5 | 71.7 |
| DER++ | 63.0 | 85.5 | 22.5 | 39.6 | 72.9 |

- On the current task every method is well calibrated (gap 2-10 points). On old tasks ER stays
  ~94 % confident at ~50 % accuracy. This is the effect H1 is about, and it is visible.
- DER++ roughly halves the confidence gap and the confident-error rate compared with ER, but its
  error-detection AUROC on old tasks is no better (72.9 vs 71.7). Both are weakness #1 in
  `phase2_method.md` showing up: part of the problem is already reduced by logit replay, so FACE
  must be compared against DER++, not ER.
- Temperature scaling helps but does not remove the gap (ER ECE old 42.3 -> 33.0).
- Energy score improves ER's old-task AUROC (71.7 -> 80.4) but not DER++'s (72.9 -> 70.6).
